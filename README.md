# Hệ Thống Quản Lý & Xuất Phiếu Lương Doanh Nghiệp (Mộc Đông Châu)

Hệ thống quản lý bảng lương, in ấn phiếu lương chuẩn khổ giấy A4, thống kê phân bổ quỹ lương theo phòng ban và xuất file chi lương ngân hàng tự động.

## 🌟 Tính Năng Nổi Bật

1. **Xem & In Phiếu Lương Chuẩn Khổ A4 (Tab 1):**
   - Định dạng chuẩn mẫu biểu 02-LĐTL, hiển thị chuyên nghiệp, vừa khít 1 trang A4.
   - Hỗ trợ in đơn lẻ từng nhân viên hoặc in hàng loạt toàn bộ công ty trong 1 lần in.
   - Xuất phiếu lương dạng PDF / HTML riêng lẻ hoặc tải trọn bộ file ZIP.

2. **Thống Kê Chi Phí & Quỹ Lương Theo Phòng Ban (Tab 2):**
   - Biểu đồ thanh ngang trực quan so sánh chi phí lương giữa các bộ phận.
   - Bảng phân tích chi tiết: Tổng lương Gross, Bảo hiểm, Thuế TNCN, Lương Net, Tỷ trọng chi phí %.

3. **Bảng Lương Tổng Hợp & Xuất Excel (Tab 3):**
   - Toàn bộ danh sách nhân viên công ty kèm đầy đủ các cột thu nhập, giảm trừ, số tài khoản.
   - Xuất file Excel (.xlsx) hoặc CSV chỉ với 1 cú click.

4. **Nạp Bảng Lương Tháng Mới (Excel / CSV):**
   - Kế toán chỉ cần kéo thả file Excel vào, hệ thống tự động nhận diện các cột và phân loại.
   - Dữ liệu xử lý 100% Client-Side trong trình duyệt, bảo mật tuyệt đối, không lưu trữ lên máy chủ bên ngoài.

5. **Xuất File Chi Lương Chuyển Khoản Ngân Hàng (TXT):**
   - Định dạng chuẩn gửi ngân hàng (BIDV iBank, Vietcombank DigiBiz, Techcombank...).
   - Chi lương lô hàng loạt cho toàn bộ nhân viên chỉ với một lệnh duyệt duy nhất.

6. **Tùy Biến Linh Hoạt (Cấu Hình):**
   - Cài đặt thông tin công ty, kỳ lương tháng, ngày chi trả, ngày công chuẩn.
   - Tự do tùy chỉnh tỷ lệ trích trừ bảo hiểm (% BHXH, % BHYT, % BHTN).

## 🚀 Hướng Dẫn Chạy

### Chạy trực tiếp qua GitHub Pages:
Truy cập: `https://nhat-hieu.github.io/Payslip_MDC/`

### Chạy trên máy tính (Localhost):
1. Chạy file `chay-he-thong.bat` hoặc mở terminal gõ:
   ```bash
   npm start
   ```
2. Mở trình duyệt truy cập: `http://localhost:3000`
